# MOOTCOACH: IMPLEMENTATION ROADMAP

## Phase 1: Foundation (Tokens & Variables)
- Implement CSS variables for the color system, typography, and spacing.
- Ensure the base HTML/CSS inherits these tokens.
- **Goal:** A consistent static aesthetic without animations.

## Phase 2: Core Components
- Build the reusable UI component library (Buttons, Cards, Inputs, Modals).
- Implement the baseline hover states (lighting, elevation).
- **Goal:** Interactive, premium-feeling static elements.

## Phase 3: Layout & Environments
- Restructure the Dashboard into the spatial "stages" (Analyse, Practice, Build, Review).
- Implement the dark cinematic environment for the Bench Simulator.
- **Goal:** Distinct visual environments for each stage.

## Phase 4: Motion & Interactions
- Introduce GSAP (or similar) for spring physics, staggered reveals, and scroll-based animations.
- Implement cursor physics (magnetic buttons, card tilts).
- **Goal:** The application feels alive and responsive.

## Phase 5: Cinematic Assets & Polish
- Integrate Higgsfield generated videos (Hero intro, loading states).
- Optimize performance (lazy loading, poster images).
- Final accessibility pass.
- **Goal:** The final "futuristic legal simulation" experience.
