# MOOTCOACH: APPLICATION DASHBOARD

## 1. Dashboard Philosophy
The main application is divided into four primary stages:
1. **ANALYSE**
2. **PRACTICE**
3. **BUILD**
4. **REVIEW**

Do not display these as four ordinary flat cards. This is a simulation environment.

## 2. Stage Navigation
- **Perspective Cards:** The stages should be represented as deep, spatial panels or perspective cards. 
- **Environmental Backgrounds:** Hovering over a stage should subtly shift the overall background environment (e.g., Practice shifts to a darker, courtroom-lit atmosphere).
- **Interactive Lighting:** As the cursor moves across the stage selection, dynamic lighting reveals the depth of the UI.

## 3. Overall Layout
- **Navigation:** Keep navigation minimal, using a left sidebar or floating bottom island (Dynamic Island style) that collapses when deep inside a simulation stage.
- **Depth:** The dashboard should feel like the "lobby" of the simulation. It should have maximum depth.
