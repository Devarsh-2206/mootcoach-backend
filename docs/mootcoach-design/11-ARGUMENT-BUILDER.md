# MOOTCOACH: ARGUMENT BUILDER

## 1. Goal
Design an advanced legal reasoning workspace. Avoid a standard, boring WYSIWYG text editor. This is where the student constructs the logic of their case.

## 2. Workspace Layout
- **Infinite Canvas / Split View:** Consider an infinite canvas where arguments can be mapped visually, OR a highly structured split view (Resource library on the left, drafting area on the right).
- **Structure:** IRAC (Issue, Rule, Application, Conclusion). The UI should encourage and enforce this structure visually through connected blocks or indented trees.

## 3. Visualizing Arguments
- **Connected Arguments:** Lines or visual links showing how a precedent in the library supports a specific point in the draft.
- **Argument Strength Indicators:** Subtle HUD elements (color-coded dots or thin bars) next to arguments indicating AI-assessed strength. 
- **Counterarguments:** Distinct visual styling (e.g., a darker panel or a red-tinted border) for mapping anticipated counterarguments.

## 4. The Hero is the Text
- **Typography:** The legal text itself must remain the hero. Use the primary Serif or Sans-Serif body font at a highly readable size (1rem to 1.125rem). 
- **Restraint:** Decorative effects (like glass panels or glowing borders) should be extremely subtle here so they never overpower the actual reading and writing experience.
